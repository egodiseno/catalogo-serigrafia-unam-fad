# Catálogo Digital de Obra Serigráfica

Prototipo público esencial para el proyecto **Catálogo Digital de Obra Serigráfica — UNAM / FAD / Taller de Serigrafía**.

## Tipo de proyecto

Catálogo digital académico/cultural para exhibición y consulta de obra serigráfica.

No es ecommerce, no incluye precios, carrito, favoritos comerciales, comentarios públicos ni funciones de venta.

## Stack actual

- HTML
- CSS
- Tailwind vía CDN
- JavaScript ligero
- JSON local controlado
- Deploy estático en Netlify
